# docs/

Tài liệu thuộc riêng GoGo-CMS. Tài liệu sản phẩm và kiến trúc chung nằm ở workspace GoGo (`GOGO_SRS.md`, `GOGO_IMPLEMENTATION_WBS.md`, `GOGO_PLACE_INGESTION_SPEC.md`…).

Dự kiến bổ sung khi Sprint 0 (CMS-001) hoàn thành:

- `permissions.md` — ma trận quyền chi tiết và cách `RoleGate` map sang từng endpoint.
- `ui-conventions.md` — DataTable, form, drawer, empty/error state dùng chung.
- `adr/` — quyết định kỹ thuật riêng của CMS (routing, table, auth flow).
